CYD Glucose Display

Flash live LibreLinkUp glucose monitoring straight to your ESP32-2432S028R ("CYD") board — directly from this page, no software to install.

⚠️ Works in Chrome or Edge only (desktop). Safari and Firefox don't support the browser feature this needs.
Your browser doesn't support Web Serial. Try Chrome or Edge on desktop. This page must be served over HTTPS to install firmware.
  1. Plug your CYD into this computer via USB.
  2. Click Install Firmware above and select the device when your browser asks.
  3. Once flashing finishes, the CYD's screen will show a WiFi network name to join (something like CYD-Glucose-Setup) and an address to visit.
  4. Join that WiFi network from your phone, open the setup page, and enter your home WiFi, LibreLinkUp login, and glucose thresholds.
  5. It reboots and starts showing glucose readings.
Source code, hardware details, and troubleshooting notes: github.com/mulscully/cyd-librelinkup-glucose-v2
